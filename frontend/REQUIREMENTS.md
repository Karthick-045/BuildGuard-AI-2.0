# Frontend Requirements & Specifications

## Technology Stack
- React 18 + Vite
- TypeScript
- Tailwind CSS
- React Router DOM
- Axios
- Lucide React
- React Flow (reactflow)

## Environment
Ensure `.env` contains:
```env
VITE_API_URL=http://localhost:8000/api
```

## Running the Application
```bash
npm install
npm run dev
```

The application will start on: `http://localhost:5173`
